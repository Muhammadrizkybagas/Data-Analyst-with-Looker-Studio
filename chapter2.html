INTERACTIVE DASHBOARD

Published

March 8, 2026

In Looker Studio, interactivity helps stakeholders quickly focus on the information that matters most. This is especially useful when analyzing trends, comparing categories, or investigating performance across different segments.

By adding filters and navigation controls, dashboards become tools for data exploration, not just data display.

1 Time Filtering

Time filtering allows users to analyze data within a specific time period. This is important for identifying trends, seasonal patterns, or performance changes over time.

Looker Studio provides built-in date filtering tools that make it easy for users to adjust the time range without modifying the dataset.

1.1 Date Range Filter

The Advanced Date Functionality is available in the date picker in Looker Studio.

This feature helps users combine marketing data from sources like Google Analytics, Google BigQuery, Google Ads, and Spreadsheets. It also allows teams to create reports, visualize results, and collaborate on dashboards using access permissions.

  1. Open the report that you want to give a rolling timeframe.
  2. Click on Edit.

Next, create a chart that matches the selected time range. Add a time series chart in Looker Studio to view data based on different date ranges.

  1. To do this, click Add as chart and select Time series chart.

On the Looker Studio space, the time series chart will be displayed.

  1. By default, charts in Looker Studio use the Auto date range, which displays data from the last 28 days.

  1. However, Looker Studio provides several options to customize the date range. You can choose a different time period by selecting Custom default date range.

  1. Next, open the date range selector under the Custom date range option in Looker Studio to see the available date range options.

  1. Then, click the date range dropdown menu in the top-right corner of the window in Looker Studio.

  1. In Looker Studio, the dropdown menu provides several date options. One of them is Fixed, which allows you to set a specific start date and end date.

Instead of showing the last 28 days, you can set a fixed range, for example May 1 to May 14.

  1. After choosing the date range in Looker Studio, click Apply.

  1. Click on View to see a preview of the date range selected.

Regardless of the date when the end-user accesses this chart and views this report, they’re always going to see the report from the first of May to the 14th of May.

Rolling Time Frame with Dynamic Dates

The Fixed date option is static, but Looker Studio also provides dynamic date options based on when the report is opened.

These options include last 7, 14, 28, or 30 days, as well as last calendar week, month, quarter, or year.

Sometimes we need more flexible date ranges that are not available in the standard options in Looker Studio.

For example, showing data from two months ago until two weeks ago, the week before yesterday, or the last three weeks excluding the current week.

To create these kinds of ranges, we need to use the Advanced date settings to customize a rolling timeframe.

2 Category Filtering

Category filtering allows users to focus on specific groups of data. Instead of showing all categories at once, users can select the category they want to analyze.

This makes dashboards easier to explore and reduces visual clutter.

2.1 Drop-down Filter

A Drop-down Filter allows users to select values from a list.

Common examples include filtering by:

  • Product category
  • Region
  • Brand or company
  • Property project

When a user selects a value from the drop-down filter, all connected charts update automatically.

3 Segmentation

Segmentation allows analysts to divide data into meaningful groups. This helps identify differences in performance between segments.

For example, sales performance may vary depending on region, product category, or marketing channel.

3.1 Segment Filtering

Segment filtering allows users to isolate specific groups of data for deeper analysis.

Examples include:

  • Viewing sales for a single region
  • Analyzing performance for one product category
  • Comparing results between customer segments

Segment filters allow decision-makers to quickly answer targeted questions without modifying the dataset.

4 Cross Interaction

Interaksi silang memungkinkan grafik dalam dasbor untuk berinteraksi satu sama lain. Alih-alih menyaring data secara manual, pengguna dapat mengklik elemen grafik untuk memperbarui grafik lain secara otomatis.

4.1 Cross-filtering

Cross-filtering enables charts to act as interactive filters.

For example:

  • Clicking on a product category in a bar chart filters other charts to show only that category.
  • Selecting a region updates revenue, demand, and KPI charts for that region.

This interaction helps users move quickly from high-level insights to detailed analysis.

5 User Exploration

A well-designed dashboard should support users who want to explore data independently. Instead of relying on static reports, users should be able to navigate the dashboard and investigate insights on their own.

5.1 Interactive Navigation

Interactive navigation helps users move between different views or sections of a dashboard.

Examples include:

  • Navigating between overview and detailed analysis pages
  • Switching between sales and marketing dashboards
  • Exploring different product segments

Navigation controls help organize complex dashboards and make them easier to use.
