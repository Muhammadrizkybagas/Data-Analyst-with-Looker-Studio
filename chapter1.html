LOOKER STUDIO FUNDAMENTALS

Published

March 5, 2026

Looker Studio is a business intelligence tool that helps transform raw data into clear and interactive dashboards. Instead of analyzing data directly from spreadsheets, analysts can visualize patterns, trends, and performance indicators in a structured way.

In business environments, dashboards are used to monitor KPIs, identify problems early, and support decision-making. Before building advanced dashboards, it is important to understand how data is connected, structured, and visualized in Looker Studio.

1 Data Connection

Before any visualization can be created, data must first be connected to the dashboard. Looker Studio allows analysts to integrate different types of datasets, including spreadsheets and external files. A proper data connection ensures that the dashboard reflects accurate and up-to-date information.

1.1 Connect Google Sheets

Google Sheets is one of the most commonly used data sources in Looker Studio. Many teams store operational data, reports, or exported system data in spreadsheets.

NoteTo connect a Google Sheet
  1. Open Looker Studio and create a new report.
  2. Click Add Data.
  3. Select Google Sheets as the data source.
  4. Choose the spreadsheet and worksheet that contains the dataset.
  5. Confirm the connection.

Once connected, Looker Studio automatically detects the available fields and allows them to be used in charts, filters, and calculations.

1.2 Import Excel / CSV Files

In some situations, data may come from external systems in Excel or CSV format. These files can also be used in Looker Studio after being uploaded or converted.

NoteA common workflow
  1. Upload the Excel or CSV file into Google Sheets.
  2. Clean and verify the data structure.
  3. Connect the spreadsheet to Looker Studio.

CSV files are often used when exporting large datasets from databases or operational systems.

2 Data Structure

Understanding how data is structured is essential before building visualizations. In Looker Studio, every dataset is composed of fields that represent either descriptive information or numerical values.

2.1 Metrics vs Dimensions

Fields in Looker Studio are categorized into dimensions and metrics.

Dimensions describe categorical information. They answer the question “what or which?”,

Examples:

  • Region
  • Product
  • Property Project
  • Sales Channel
  • Date

Metrics represent numerical values that can be measured and aggregated.

Examples:

  • Revenue
  • Number of Units Sold
  • Leads Generated
  • Marketing Cost

For Example:

Dimension Metric
Project Name Revenue
Region Units Sold
Month Marketing Spend
Note

Dimensions group the data, while metrics provide the values being analyzed.

2.2 Aggregation Logic

Metrics are usually calculated using aggregation functions. Aggregation determines how multiple records are summarized in a chart.

SUM

  • Adds all values together.
  • Example: total revenue across projects.

AVG (Average)

  • Calculates the average value.
  • Example: average marketing cost per campaign.

COUNT

  • Counts the number of records.
  • Example: number of transactions.

Choosing the correct aggregation ensures that the dashboard reflects the real performance of the business.

Incorrect aggregation can lead to misleading insights.

3 Chart Basics

Charts help transform numerical data into visual insights. Instead of reading rows of numbers, users can quickly identify patterns, comparisons, and trends.

3.1 Basic Chart Types

Choosing the right chart is important because different charts serve different analytical purposes. Below are several common chart types that are widely used in Looker Studio dashboards.

Example dataset:

3.1.1 Bar Chart

Bar charts are used to compare values across different categories. They are one of the most commonly used charts in business dashboards.

3.1.2 Line Chart

Line charts are used to visualize trends or ordered comparisons. Since this dataset does not contain time variables, we can use the chart to compare average selling price across companies.

3.1.3 Pie Chart / Doughnut Chart

Pie charts show how different categories contribute to a total.

3.1.4 Scatter Plot

Scatter plots help analyze relationships between two numerical variables.

3.1.5 Histogram

Histograms show how frequently values fall within certain ranges. This helps analysts understand the distribution of a dataset.

3.1.6 Area Chart

Area charts are similar to line charts but emphasize the magnitude of change over time.

3.1.7 Scorecard

Scorecards display a single KPI value with optional comparison indicators.

3.2 Chart Configuration

After selecting a chart type, it is important to configure it correctly to ensure accurate reporting.

Key chart settings include:

  • Dimension Selection → Defines how data is grouped.
  • Metric Selection → Determines what values are displayed.
  • Sorting → Controls the order of data, such as ranking projects by revenue.
  • Date Range → Limits the data to a specific time period.
  • Labels and Titles →Provide context so users understand what the chart represents.

Proper configuration ensures that charts present reliable and meaningful information for decision-making.
